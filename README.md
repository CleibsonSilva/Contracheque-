# Meu Contracheque v3

PWA offline. Envie todos os arquivos para a raiz do repositório GitHub Pages. Primeira abertura pede salário e escala. Baseado nas regras de ciclo do Minha Escala e no conceito de registro diário do Papa Hora.

**Limitações:** previsão estimada; horário noturno e DSR dependem da convenção coletiva, não inclui automaticamente prorrogações após 5h, feriados, descontos IRRF e todas as incidências sobre reflexos. O sistema presume trabalho nos turnos previstos até o usuário desmarcar. Dados locais; exporte backups.
