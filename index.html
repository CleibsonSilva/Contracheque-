Dados do salário

O adicional noturno é calculado sobre horas noturnas registradas, não automaticamente sobre todo plantão previsto. Para turnos noturnos, confira o horário efetivo e a convenção coletiva. O DSR padrão de 16,67% é apenas uma aproximação baseada no exemplo. O valor real depende dos dias úteis, repousos e critérios da folha.

Backup dos dados

Os dados ficam salvos neste navegador. Faça backups periódicos, especialmente antes de limpar dados ou trocar de aparelho.

Instalar aplicativo

No Android, abra o menu do navegador e escolha “Adicionar à tela inicial” ou “Instalar app”. No iPhone, use Compartilhar → Adicionar à Tela de Início.
